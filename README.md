# Golden Apple Website

Responsive static website built with HTML, CSS and a small amount of JavaScript. No build tools or dependencies required.

## Preview locally
Open `index.html` in a web browser.

## Upload to GitHub Pages
Upload the contents of this folder to the root of your existing GitHub repository, keeping `index.html` in the root and the `assets` folder alongside it. Commit the changes. In GitHub, open Settings → Pages and keep the repository's existing deployment source/branch settings.
